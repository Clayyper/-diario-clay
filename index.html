Preparando banco…

Salva os dados no IndexedDB deste navegador, com alternativa de armazenamento local. Exporte JSON para não perder o histórico ao trocar de aparelho, limpar dados ou abrir uma cópia diferente do arquivo.

Para registrar pelo ChatGPT, me envie as informações. Há uma cópia do aplicativo e dos dados no repositório privado do GitHub. Este HTML ainda salva alterações apenas neste dispositivo e não sincroniza sozinho. Publicação online e login seguro exigem uma camada de autenticação; nunca cole tokens do GitHub no aplicativo.

Privacidade e precisão: no GitHub Pages, o site busca seus registros dos arquivos JSON publicados e funciona em modo de leitura. Para registrar novos dados, informe à Sophie e aguarde a confirmação de gravação no GitHub. Os dados de saúde ficam públicos enquanto este repositório for público.
